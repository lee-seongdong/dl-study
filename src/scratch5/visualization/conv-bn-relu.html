ConvBlock 안에서 값이 바뀌는 과정

U-Net의 ConvBlock은 Conv2d, BatchNorm2d, ReLU를 두 번 반복합니다. 텐서의 모양을 바꾸는 연산은 Conv2d뿐이고, BatchNorm2d와 ReLU는 모양을 그대로 두고 값만 바꿉니다.

down1 = ConvBlock(1, 64)의 흐름

작은 배치로 직접 계산하기

노트북과 같은 연산을 8×8 이미지 4장과 출력 채널 2개로 줄여서 브라우저에서 실제로 계산합니다. 커널 값은 설명을 위해 고른 값이고, 실제 모델에서는 학습으로 정해집니다.

class ConvBlock(nn.Module):    def __init__(self, in_ch, out_ch):        super().__init__()        self.convs = nn.Sequential(            nn.Conv2d(in_ch, out_ch, 3, padding=1),            nn.BatchNorm2d(out_ch),            nn.ReLU(),            nn.Conv2d(out_ch, out_ch, 3, padding=1),            nn.BatchNorm2d(out_ch),            nn.ReLU()        )     def forward(self, x):        return self.convs(x)

model.train()과 model.eval()에서 BatchNorm2d가 쓰는 통계

  
train 상태의 BatchNorm2d는 지금 들어온 배치의 μ와 σ를 씁니다. 그래서 같은 이미지라도 함께 넣은 이미지가 달라지면 결과가 달라집니다. eval 상태에서는 학습하면서 누적한 running_mean과 running_var를 쓰므로 배치 구성과 관계없이 결과가 같습니다.
