VAE와 무엇이 다른가

    
    
VAE의 병목에는 목적이 있습니다. 정보를 z로 압축하고 z를 N(0, I) 근처에 모아 두어야, 생성할 때 N(0, I)에서 뽑은 z로 새 이미지를 만들 수 있습니다. U-Net에는 이런 잠재변수가 없어서 혼자서는 생성 모델이 아닙니다. 대신 입력과 같은 모양의 출력을 픽셀 단위로 정확하게 만드는 일에 집중합니다.

  


  

    
확산모델에서 U-Net이 맡는 일

    
확산모델에서 U-Net은 노이즈가 섞인 이미지 x_t를 받아 그 안에 섞인 노이즈 ε를 예측합니다. 입력과 출력이 모두 1×28×28이어야 하므로 U-Net의 구조가 그대로 맞습니다. 같은 이미지라도 단계 t에 따라 섞인 노이즈의 양이 다르므로 t도 입력해야 하고, 02_diffusion_model.ipynb의 pos_encoding이 정수 t를 벡터 v로 바꿉니다.

    
    
ConvBlock이 v를 받는 일반적인 방식은 다음과 같습니다. 다음 노트북의 실제 구현과 세부는 다를 수 있습니다.


# 시간 벡터 v를 받도록 바꾼 ConvBlock.forward의 일반적인 형태
def forward(self, x, v):          # v: pos_encoding(t)로 만든 벡터
    N, C, _, _ = x.shape
    v = self.mlp(v)               # Linear로 길이를 채널 수 C에 맞춘다
    v = v.view(N, C, 1, 1)        # 채널마다 숫자 하나가 된다
    return self.convs(x + v)      # 같은 채널의 모든 픽셀에 같은 값을 더한다
